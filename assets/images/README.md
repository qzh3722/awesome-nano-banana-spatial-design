# Assets Directory

This directory contains all images used in the case documentation.

## File Naming Convention

Images should follow this naming pattern:
```
[CASE-ID]-[input|output]-[descriptor].jpg
```

Examples:
- `A-001-input-cad-plan.jpg` - Input CAD drawing for case A-001
- `A-001-output-modern-styled.jpg` - Output result for case A-001
- `I-015-output-comparison-1.jpg` - First comparison for case I-015

## Image Requirements

- **Format**: JPG or PNG
- **Minimum Resolution**: 1920px on longest side
- **File Size**: Keep under 5MB per image
- **Quality**: Professional-grade examples only

## Image Optimization

Before committing images:
1. Crop to relevant content
2. Resize to appropriate dimensions (1920-4096px range)
3. Compress to reasonable file size (aim for 1-3MB)
4. Use descriptive filenames
