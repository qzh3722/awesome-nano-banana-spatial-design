# Contributing to Awesome Nano Banana Spatial Design

Thank you for your interest in contributing! This guide will help you submit high-quality use cases and improvements.

## How to Contribute

### 1. Types of Contributions

We welcome:

- **New Use Cases**: Submit complete prompt examples following our template
- **Improved Prompts**: Enhance existing cases with better parameters or descriptions
- **Translations**: Help improve Chinese translations or add other languages
- **Documentation**: Fix typos, clarify instructions, or add helpful tips
- **Example Images**: Provide high-quality example outputs for cases

### 2. Submission Guidelines

#### For New Use Cases

1. **Check for duplicates**: Search existing cases to avoid overlap
2. **Use the template**: Copy [CASE_TEMPLATE.md](./CASE_TEMPLATE.md) as your starting point
3. **Follow naming convention**: `[CATEGORY-NUMBER]-descriptive-name.md`
   - Architecture: `A-001`, `A-002`, etc.
   - Interior: `I-001`, `I-002`, etc.
   - Landscape: `L-001`, `L-002`, etc.

4. **Quality standards** - Your case must include:
   - Clear problem statement in both English and Chinese
   - Complete, tested prompt with placeholders
   - Optimal parameters (document what you tested)
   - At least one high-quality example output (min 1920px width)
   - Practical tips from real usage
   - Links to related cases

5. **Test your prompt**: Generate at least 3-5 outputs to ensure consistency before submitting

#### For Translations

- Maintain technical terminology consistency
- Preserve formatting and structure
- Ensure Chinese translations are natural and professional
- Review both versions for accuracy

#### For Documentation

- Use clear, concise language
- Follow existing markdown formatting
- Provide examples where helpful
- Keep bilingual parity (update both EN and CN versions)

### 3. Submission Process

#### Option A: GitHub Issues (Easier)

1. Go to [Issues](https://github.com/qzh3722/awesome-nano-banana-spatial-design/issues)
2. Click "New Issue" and select appropriate template
3. Fill in all required information
4. Attach example images if applicable
5. Submit for review

#### Option B: Pull Request (Preferred for multiple contributions)

1. **Fork** the repository
2. **Create a branch** for your contribution:
   ```bash
   git checkout -b feature/add-case-A-031
   ```
3. **Add your files**:
   - New case markdown file in appropriate folder
   - Example images in `assets/images/`
   - Update category README.md with your case
4. **Commit** with clear message:
   ```bash
   git commit -m "Add A-031: Parametric Facade Exploration case"
   ```
5. **Push** to your fork:
   ```bash
   git push origin feature/add-case-A-031
   ```
6. **Open a Pull Request** with description of your contribution

### 4. Review Process

All contributions will be reviewed for:

- **Technical accuracy**: Prompts work as described
- **Quality**: Professional-grade examples and clear documentation
- **Completeness**: All required sections filled out
- **Originality**: Provides unique value to the collection
- **Bilingual quality**: Both English and Chinese versions are complete

Expect feedback within 5-7 days. We may request revisions before merging.

### 5. Content Standards

#### Writing Style

- Be concise and professional
- Use active voice
- Provide practical, actionable guidance
- Include real-world context and use cases
- Avoid marketing language or hype

#### Technical Requirements

- Prompts must be reproducible
- Parameters should be tested and optimal
- Example outputs must be properly attributed
- All placeholders clearly marked as `{PLACEHOLDER}`

#### Image Guidelines

- Minimum resolution: 1920px on longest side
- Format: JPG or PNG
- File size: Keep under 5MB per image
- Naming: `[case-id]-[input/output]-[descriptor].jpg`
  - Example: `A-001-output-modern-living.jpg`

### 6. Code of Conduct

- Be respectful and constructive
- Credit others' work appropriately
- No spam or self-promotion
- Focus on helping the design community

### 7. Recognition

Contributors will be:

- Listed in case credits (Contributor field)
- Acknowledged in README if making significant contributions
- Invited to join as collaborators after consistent quality contributions

### 8. Questions?

- Check existing [Issues](https://github.com/qzh3722/awesome-nano-banana-spatial-design/issues)
- Join [Discussions](https://github.com/qzh3722/awesome-nano-banana-spatial-design/discussions)
- Reach out to maintainers
