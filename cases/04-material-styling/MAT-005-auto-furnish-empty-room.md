## Prompt Template / 提示词模板

### English Version

```
Redesign this room according to my specified style. Act as a professional interior designer and completely transform this space as if starting from an empty shell.

CRITICAL - Maintain from the uploaded photo:
- Exact same camera angle and perspective
- Same viewing position and field of view
- Same room proportions as shown

You may modify everything else:
- All furniture
- Wall colors/finishes/treatments
- Ceiling design and treatments
- Flooring materials and colors
- Window treatments (curtains, blinds)
- Lighting fixtures
- Built-in features (shelving, fireplace surround, cabinetry)
- All decorative elements

Structural changes NOT allowed:
- Do not add, remove, or relocate windows
- Do not add, remove, or relocate doors
- Do not modify wall positions

Apply professional design principles. Create a magazine-quality result.

The room purpose and style I want: [Specify room type, color palette, and design style]
```

### 中文版

```
根据我指定的风格重新设计这个房间。以专业室内设计师的身份，将这个空间彻底改造，如同从空壳开始设计。

关键要求 - 必须保持上传照片中的：
- 完全相同的相机角度和透视
- 相同的观看位置和视野范围
- 照片中显示的房间比例

可以修改的内容：
- 所有家具
- 墙面颜色/饰面/处理
- 天花板设计和处理
- 地面材料和颜色
- 窗帘处理（窗帘、百叶窗）
- 灯具照明
- 内置功能（搁架、壁炉装饰、柜体）
- 所有装饰元素

不允许的结构性改变：
- 不要添加、移除或移动窗户
- 不要添加、移除或移动门
- 不要改变墙体位置

运用专业设计原则。创造杂志级别的效果。

我想要的房间用途和风格：[指定房间类型、色彩方案和设计风格]
```

## 💡 Tips / 使用技巧

### How to Write Effective Customization / 如何编写有效的个性化指令

**Structure your request with these elements / 用以下要素构建你的需求：**

1. **Room Type / 房间类型**: bedroom, living room, home office, dining room, etc.
2. **Color Palette / 色彩方案**: specific colors or tones (blue and white, cream, earth tones, etc.)
3. **Design Style / 设计风格**: modern, Scandinavian, French luxury, industrial, minimalist, etc.
4. **Special Features / 特殊功能** (optional): TV wall, study area, reading nook, etc.

### Examples / 示例

| Room Type | Color | Style | Special Feature |
|-----------|-------|-------|-----------------|
| Boy's Bedroom | Blue & White | Vibrant, Playful | Age-appropriate (10 years) |
| Master Bedroom | Cream | French Light Luxury | Cozy atmosphere |
| Living Room | Neutral | Modern | Full-wall TV cabinet |
| Home Office | White & Wood | Scandinavian | Built-in bookshelf |
| Nursery | Soft Pink | Whimsical | Safe, child-friendly |

### Best Practices / 最佳实践

**English:**
- Be specific about the intended user (e.g., "10-year-old boy" vs just "child")
- Include mood descriptors (cozy, vibrant, calm, luxurious)
- Mention key furniture pieces if important to your vision
- The AI will match furniture scale to room proportions automatically

**中文:**
- 明确指定使用者（如"10岁男孩"而非仅"儿童"）
- 包含氛围描述词（舒适、活泼、沉静、奢华）
- 如果对你的设想很重要，请提及关键家具
- AI会自动将家具比例与房间尺寸匹配
