# Specialized Tasks / 专项应用

> Special use cases & advanced features | 特殊场景与高级功能

## 工作流阶段说明 / Workflow Stage Description

### 中文

**专项应用**是设计流程的第六阶段，涵盖特殊需求和高级功能的应用场景。这个阶段的提示词针对特定的专业需求，如多语言文字渲染、图像编辑、一致性视觉设计等。

**适用场景**:
- 在设计中渲染多语言文字（标识、导视、海报）
- 图像编辑和后期处理（角度、深度、光照、色彩调整）
- 品牌视觉一致性设计（保持角色、物体的视觉统一）
- 特殊视角和投影（轴测图、等角图、爆炸图）
- 技术分析图（流线分析、功能分区、日照分析）
- 动画关键帧和分镜设计

**典型用例**:
- 导视系统中的多语言标识设计
- 建筑海报和宣传册的文字排版
- 调整已有效果图的光照、色调、景深
- 保持品牌吉祥物在不同场景的视觉一致性
- 生成轴测分析图和技术示意图
- 季节对比效果图（同一场景的四季变化）
- 照明方案对比（自然光 vs 人工照明）

### English

**Specialized Tasks** is the sixth stage of the design workflow, covering special requirements and advanced feature applications. Prompts in this stage address specific professional needs such as multilingual text rendering, image editing, and visual consistency design.

**Use Cases**:
- Render multilingual text in designs (signage, wayfinding, posters)
- Image editing and post-processing (angle, depth, lighting, color grading)
- Brand visual consistency design (maintaining character/object visual unity)
- Special viewpoints and projections (axonometric, isometric, exploded views)
- Technical analysis diagrams (circulation analysis, zoning, sunlight studies)
- Animation keyframes and storyboard design

**Typical Examples**:
- Multilingual signage design in wayfinding systems
- Text layout for architectural posters and brochures
- Adjust lighting, tone, depth of field in existing renders
- Maintain brand mascot visual consistency across different scenes
- Generate axonometric analysis diagrams and technical illustrations
- Seasonal comparison renders (same scene in four seasons)
- Lighting scheme comparisons (natural vs artificial lighting)
