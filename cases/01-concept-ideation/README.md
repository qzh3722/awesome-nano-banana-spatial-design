# Concept Ideation / 概念构思

> From zero to creative solutions | 从零到创意方案

## 工作流阶段说明 / Workflow Stage Description

### 中文

**概念构思**是设计流程的第一阶段，适用于从零开始创建创意方案的场景。这个阶段的提示词帮助设计师快速生成多个设计概念、探索不同风格方向、可视化初步想法。

**适用场景**:
- 客户提出模糊需求，需要快速生成多个概念方案
- 头脑风暴阶段，探索不同设计风格和方向
- 通过文字描述直接生成可视化概念图
- 为客户演示多个设计选项以确定方向

**典型用例**:
- 根据简报要求生成多个风格方向的概念图
- 文字描述转视觉概念（如"现代简约办公室"→概念效果图）
- 情绪板和氛围图生成
- 快速概念草图可视化

### English

**Concept Ideation** is the first stage of the design workflow, used when creating creative solutions from scratch. Prompts in this stage help designers quickly generate multiple design concepts, explore different style directions, and visualize initial ideas.

**Use Cases**:
- Client provides vague requirements, need to quickly generate multiple concept options
- Brainstorming phase, exploring different design styles and directions
- Generate visual concepts directly from text descriptions
- Present multiple design options to clients for direction confirmation

**Typical Examples**:
- Generate concept images in multiple style directions based on brief
- Text description to visual concept (e.g., "modern minimalist office" → concept render)
- Mood board and atmosphere image generation
- Quick concept sketch visualization
