# Space Planning / 空间规划

> Layout optimization & circulation design | 布局优化与动线设计

## 工作流阶段说明 / Workflow Stage Description

### 中文

**空间规划**是设计流程的第二阶段，专注于优化布局和动线设计。这个阶段的提示词帮助设计师生成家具布局、优化空间利用、设计人流动线、确定功能分区。

**适用场景**:
- 根据房间尺寸生成多种家具布局方案
- 优化现有空间的功能分区和动线
- 测试不同布局选项的空间效率
- 生成俯视平面图展示空间组织

**典型用例**:
- 家具布局生成（客厅、卧室、办公室等）
- 开放式空间的功能分区设计
- 动线优化和通道宽度验证
- 多功能空间的灵活布局设计
- 办公室工位布局和会议区规划

### English

**Space Planning** is the second stage of the design workflow, focused on layout optimization and circulation design. Prompts in this stage help designers generate furniture layouts, optimize space utilization, design circulation paths, and define functional zones.

**Use Cases**:
- Generate multiple furniture layout options based on room dimensions
- Optimize functional zoning and circulation in existing spaces
- Test space efficiency of different layout options
- Generate top-down floor plans showing spatial organization

**Typical Examples**:
- Furniture layout generation (living room, bedroom, office, etc.)
- Functional zoning design for open-plan spaces
- Circulation optimization and pathway width validation
- Flexible layout design for multi-functional spaces
- Office desk layout and meeting area planning
