# Case 5.2: Lighting Enhancement (Post-production 1) / 洗图1：光影修复与强化 `[Original]`

> **Scene Rendering / Post-production.**
>
> Enhance lighting quality in interior renderings: add light source glow, recover shadow details, improve light falloff, and boost spatial depth.
>
> **场景渲染 / 后期处理。**
>
> 增强室内渲染图的光照品质：强化灯具光晕、恢复暗部细节、优化光线衰减、提升空间层次。

### English Prompt

```
Enhance the lighting quality of this interior rendering while strictly preserving all geometry, furniture, and design elements:

AUTOMATIC LIGHTING ANALYSIS & ENHANCEMENT:
1. Analyze all visible light sources (chandeliers, lamps, windows, recessed lights) and intensify their glow with natural bloom effects

2. Recover shadow details in dark areas while maintaining depth - reveal hidden textures without washing out the image

3. Apply realistic light falloff based on inverse-square law - objects closer to light sources should be noticeably brighter

4. Add subtle ambient light bounce on ceilings and walls from illuminated surfaces below

5. Enhance depth perception through lighting - create clear brightness separation between foreground and background

STRICT PRESERVATION:
- Maintain exact geometry, colors, materials, and spatial layout
- Do not add, remove, or modify any objects
- Keep the original atmosphere and design intent

OUTPUT: Professional photography-quality lighting that feels natural and atmospheric.
```

### 中文提示词

```
增强这张室内渲染图的光照品质，同时严格保留所有几何形状、家具和设计元素：

自动光影分析与增强：
1. 分析所有可见光源（吊灯、台灯、窗户、筒灯），强化光晕并添加自然的光线扩散效果

2. 恢复暗部区域的细节同时保持画面深度——显现隐藏的纹理，避免过度曝光

3. 应用真实的平方反比光线衰减——靠近光源的物体应明显更亮

4. 在天花板和墙面上添加来自下方照明表面的微妙环境光反射

5. 通过光影增强景深感——在前景和背景之间创建清晰的明暗层次分离

严格保真：
- 保持精确的几何形状、颜色、材质和空间布局
- 不添加、移除或修改任何物体
- 保持原有的氛围和设计意图

输出：呈现自然且富有氛围感的专业摄影级灯光效果。
```

### Meta-Prompt Template / 元提示词模板

**Step 1: Use this prompt to analyze the image and generate a custom enhancement prompt:**

```
Analyze this interior rendering and identify specific lighting issues that need improvement:

STEP 1 - DIAGNOSTIC ANALYSIS:
List all detected lighting problems:
- Light source glow quality (weak/strong/natural)
- Shadow areas (over-dark/detail-lost/acceptable)
- Light falloff (flat/realistic/over-dramatic)
- Ceiling brightness (too dark/balanced/over-lit)
- Depth separation (flat/moderate/good)
- Any overexposed or underexposed areas

STEP 2 - GENERATE CUSTOM PROMPT:
Based on your analysis, generate a targeted lighting enhancement prompt that:
- Addresses ONLY the specific issues identified
- Prioritizes the most impactful improvements
- Uses precise technical language for AI image generation
- Includes geometry preservation safeguards

OUTPUT FORMAT:
## Lighting Issues Detected:
[Bullet list of specific problems]

## Custom Enhancement Prompt:
[Ready-to-use prompt tailored to this specific image]
```

**Step 2: Copy the AI-generated custom prompt and use it with your image.**

## 💡 Tips / 技巧

### When to Use Each Method / 何时使用哪种方法

| Scenario | Recommended Method |
|----------|-------------------|
| Quick fix, good enough | Method A (Universal) |
| Best possible result | Method B (Meta-Prompt) |
| Batch processing | Method A (Universal) |
| Portfolio/presentation | Method B (Meta-Prompt) |
