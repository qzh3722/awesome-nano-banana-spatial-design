## 🚀 Getting Started / 快速开始

1. **Identify your design phase**: Are you planning layouts, selecting materials, or styling spaces?
2. **Gather inspiration**: Collect reference images for materials, furniture, or style preferences
3. **Start specific**: Use detailed material and color descriptions for better results
4. **Iterate quickly**: Generate multiple options to present to clients
