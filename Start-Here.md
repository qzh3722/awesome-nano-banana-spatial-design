# Start Here | How to Use This Repository

This repository is designed for **spatial designers at different AI experience levels**.  
If this is your first time here, please start with the path that matches you best.

---

## 🟢 If you are new to AI in spatial design

**Start with:**
- [Concept Ideation / Stage 1](./README.md#-concept-ideation)
- Specifically: [1.1 Auto-Furnish Floor Plan](./README.md#11-auto-furnish-floor-plan)

**Goal:**
- Learn how to translate vague client intentions into design directions
- Understand how prompts help structure early thinking, not replace it

> ⚠️ Do NOT aim for final results at this stage. Focus on exploration.

---

## 🟡 If you want faster floor plan or layout iteration

**Start with:**
- [2.1 Colored Floor Plan](./README.md#21-colored-floor-plan)
- [2.5 Office Layout Planning](./README.md#25-office-layout-planning)

**Goal:**
- Explore how AI assists in layout prototyping
- Learn what can be automated and what still requires designer judgment

> ⚠️ Expect manual adjustments. AI output is a starting point.

---

## 🔵 If you want to understand prompt structure itself

**Focus on:**
- Prompt anatomy inside each example
- Usage Notes and limitations (Tips sections)
- JSON vs Natural Language comparison in [Case 2.1](./README.md#21-colored-floor-plan)

**Goal:**
- Learn how to **rewrite prompts**, not just reuse them
- Understand when to use simple prompts vs structured JSON

---

## Important Notes

- Prompts in this repository are **templates**, not final answers
- Results depend heavily on project context and constraints
- Designer judgment is always required before client delivery
- All prompts are designed for **Gemini 3 Pro Image** (Nano Banana Pro)

**If you are unsure where to start:**  
👉 Begin with [Concept Ideation / Stage 1](./README.md#-concept-ideation)
